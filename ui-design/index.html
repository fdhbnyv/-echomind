Hi-Fi UI Design · 2026-09
声念 EchoMind · 界面设计稿
将碎片思维，一语成章。围绕「零步骤录音 · 无干扰 · 即时反馈 · 暗色刚需」四条产品原则重设计主界面；已选定「纸语」方向，核心流程按纸语延续，另附两个备选方向。
设计前提
以现有 Android 版（Kotlin + Compose）为基础：写 / 记录 / 设置三 Tab、记忆系统、6 套主题、桌面 Widget 与 Siri 式浮层均已实现。本稿不推翻功能，只重塑信息层级与情绪。
方向 B · 纸语（已选定 · 推荐落地）
暖白纸感 + 墨色声纹环。衬线标题，记事本气质，适合「每日复盘」这类安静场景。对应现有「纸质风」主题，核心流程五屏均按此延续。
方向 A · 声光（备选一）
深空玻璃 + 电光声核。录音按钮升级为「声之核」光球：呼吸动画引导说话，声纹涟漪扩散。对应现有「液态玻璃」主题。
方向 C · 墨线（备选二）
高对比漫画风：纯黑描边、速度感光球、红黄撞色。对应现有「漫画風」主题，受众更年轻、情绪更张扬。
结构变化
① 底部导航建议加「记忆」Tab（代码已实现未挂导航）；② 首页去掉大输入框，语音为绝对主角，文字输入收敛为左下角小入口；③ 整理结果增加「你说……」原话引用。
首页 · 三个方向
同一产品、三种气质：语音即输入，首页即录音态
